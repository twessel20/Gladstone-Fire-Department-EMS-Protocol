# Gladstone Fire Department EMS Protocols

Mobile-first, offline-ready quick-reference application for Gladstone Fire Department EMS protocols.

## Current status
This repository contains the Gladstone Fire Department EMS field-reference application. The protocol dataset is indexed from the approved 2026 GFD EMS Protocol V3 source manual.

**Do not use the current build for patient-care decisions until the GFD protocol dataset has been loaded and validated.**

## Planned features
- Searchable GFD EMS protocols
- EMT / Paramedic role views
- Favorites and offline access
- Source-PDF links
- GFD medication references and protocol-linked calculators
- Patient home-medication lookup
- Pill identifier and prescription-based pill count
- Mobile-first field interface

## Clinical source
The approved Gladstone Fire Department EMS protocol manual and Medical Control remain authoritative.
